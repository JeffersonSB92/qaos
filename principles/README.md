# Principles

Principles are stable and abstract Quality Engineering philosophy that guides how the QAOS thinks about quality.

They are client-, stack-, and tool-independent. They should remain relatively stable and guide decisions rather than prescribe implementation.

Do not store detailed technical rules, project exceptions, tool instructions, or framework-specific practices here.
