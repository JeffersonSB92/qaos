# Standards

Standards are objective and verifiable technical rules adopted by the QAOS.

They must be clear, verifiable, and valid independently of any client. Client-specific exceptions belong to project context or project decisions. Quality gates may verify standards.

Do not store optional suggestions, stack-specific practices, unvalidated knowledge, or client-specific decisions here.

```text
principle
    ↓
standard
    ↓
quality gate
```
