# Learnings

In the main QAOS, learnings are generalized practical knowledge derived from real project experience that has been sanitized and accepted into the consultancy knowledge base but has not yet matured into another QAOS component.

Learnings arise from practical experience. Client information must be removed before entering the main QAOS. They may later mature into a pattern, anti-pattern, standard, skill, playbook, adapter, or knowledge synthesis.

```text
client/learnings/
= raw, project-level learning candidates

qaos/learnings/
= sanitized and generalized consultancy knowledge
```
